# Mechanism Simulation Skill

Build simulation in layers.

Layer 1:
- static transforms.

Layer 2:
- ideal gear kinematics.

Layer 3:
- constraints and collision/interference checks.

Layer 4:
- torque/power propagation.

Layer 5:
- simplified balance/escapement dynamics.

Do not jump directly to a full physics engine. The goal is traceable watch-specific mechanics, not generic rigid-body spectacle.
