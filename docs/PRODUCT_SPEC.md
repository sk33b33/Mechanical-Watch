# Product Specification

## Working name
Mechanical Watchmaker 3D

## Primary experience
Build a mechanical watch from an empty movement through an interactive parametric 3D workspace.

## Core interaction
Select component → edit parameters → regenerate geometry → validate → simulate.

## Primary screens
1. Design workspace
2. Component library
3. Properties inspector
4. Validation console
5. Simulation controls
6. Measurements
7. Project browser

## Starter movement
The first sample movement should be deliberately simple and explicitly labeled as a teaching/demo movement. It must not be presented as a production-caliber design.
