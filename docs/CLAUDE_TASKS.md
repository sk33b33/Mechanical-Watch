# Initial Claude Code Tasks

Run these in order.

## Task 1
Create the TypeScript application skeleton, test infrastructure and strict linting.

## Task 2
Implement `Length`, `Angle`, `Time`, `AngularVelocity`, `Torque` domain units.

## Task 3
Implement parametric gear mathematics and tests.

## Task 4
Implement `Gear`, `Shaft`, `GearMesh` and a deterministic gear-train solver.

## Task 5
Create the first Three.js viewport and render generated gears from domain state.

## Task 6
Add component selection and an inspector.

## Task 7
Add validation and an always-visible validation console.

## Task 8
Create a small educational demo movement and drive its animation exclusively from the kinematic solver.

After every task:
- run tests;
- run typecheck;
- inspect for duplicated sources of truth;
- update documentation;
- do not proceed if the foundation is broken.
